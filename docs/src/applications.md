# Applications

AUSAXS uses the same Debye-equation engine for every application. What changes is the sample and the probe. 

## Molecules in solution

<div class="ausaxs-apps" markdown>

<div class="ausaxs-app" markdown>
<span class="ausaxs-app__art">:ausaxs-art-saxs:</span>

[SAXS](saxs.md){ .ausaxs-app__title }

Calculate the X-ray scattering profile of a protein or other biomolecule, and fit it to measured data.
</div>

<div class="ausaxs-app" markdown>
<span class="ausaxs-app__art">:ausaxs-art-sans:</span>

[SANS](sans.md){ .ausaxs-app__title }

The SAXS pipeline with neutron scattering lengths, with control over the D₂O fraction and hydrogen exchange.
</div>

<div class="ausaxs-app" markdown>
<span class="ausaxs-app__art">:ausaxs-art-rigidbody:</span>

[Rigid-body refinement](rigid-body-refinement.md){ .ausaxs-app__title }

Refine multi-domain proteins and complexes against SAXS or SANS data.
</div>

<div class="ausaxs-app" markdown>
<span class="ausaxs-app__art">:ausaxs-art-em:</span>

[EM map validation](em.md){ .ausaxs-app__title }

Validate a cryo-EM map against solution SAXS data.
</div>

</div>
