# Citing AUSAXS

If you use AUSAXS in your work, please cite the paper describing the SAXS profile calculation:

> K. Lytje and J. S. Pedersen. Small-angle X-ray scattering profile calculation for high-resolution models of biomacromolecules. _J. Appl. Cryst._ **58**, 1332–1346 (2025). doi: [10.1107/S160057672500562X](https://doi.org/10.1107/S160057672500562X)

```bibtex
@article{Lytje2025,
  author  = {Lytje, Kristian and Pedersen, Jan Skov},
  title   = {Small-angle {X}-ray scattering profile calculation for high-resolution models of biomacromolecules},
  journal = {Journal of Applied Crystallography},
  volume  = {58},
  number  = {4},
  pages   = {1332--1346},
  year    = {2025},
  doi     = {10.1107/S160057672500562X}
}
```

For the theory behind small-angle scattering of biomolecules, both X-rays and neutrons, and the approximations made by AUSAXS and other programs, see our paper:

> K. Lytje, J. S. Pedersen and J. S. Hub. Small-angle solution scattering: from fundamental theory to practical approximations. _Rep. Prog. Phys._ **89** (2026). doi: [10.1088/1361-6633/aead1d](https://doi.org/10.1088/1361-6633/aead1d)

```bibtex
@article{Lytje2026,
  author  = {Lytje, Kristian and Pedersen, Jan Skov and Hub, Jochen S.},
  title   = {Small-angle solution scattering: from fundamental theory to practical approximations},
  journal = {Reports on Progress in Physics},
  volume  = {89},
  year    = {2026},
  doi     = {10.1088/1361-6633/aead1d}
}
```

If you use the [EM map validation](cli/em-validation.md), please also cite:

> K. Lytje and J. S. Pedersen. Validation of electron-microscopy maps using solution small-angle X-ray scattering. _Acta Cryst. D_ **80**, 493–505 (2024). doi: [10.1107/S2059798324005497](https://doi.org/10.1107/S2059798324005497)

```bibtex
@article{Lytje2024,
  author  = {Lytje, Kristian and Pedersen, Jan Skov},
  title   = {Validation of electron-microscopy maps using solution small-angle {X}-ray scattering},
  journal = {Acta Crystallographica Section D: Structural Biology},
  volume  = {80},
  number  = {7},
  pages   = {493--505},
  year    = {2024},
  doi     = {10.1107/S2059798324005497}
}
```
